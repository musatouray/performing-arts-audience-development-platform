# fabric/bi-finance

**Managed by Fabric Git integration. Don't hand-edit.**

The DEV workspace syncs its items here: notebooks, pipelines, semantic models and reports, each as an `<name>.<ItemType>/` folder with a `.platform` file.
Create or change items in the Fabric UI (or a feature workspace), then **Source control › Commit**.
Deployment pipelines promote from the DEV workspace to TEST and PROD.

## Exceptions to "don't hand-edit"

- `rp_finance.Report` is generated by `scripts/bi/build_rp_finance.py` (layout, theme and visuals as code).
  Change the script, run `python scripts/bi/build_rp_finance.py fabric/bi-finance/rp_finance.Report`, commit, then **Update all** in the workspace.
  Edits made in the Fabric UI are overwritten the next time the script runs, so make them in the script.
- `rp_finance.pbip` opens the report and `sm_finance.SemanticModel` together in Power BI Desktop. Fabric doesn't create it.
